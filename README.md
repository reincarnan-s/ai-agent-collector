# 🤖 AI Agent 技术文章收集器

一个为计算机学生设计的本地网页应用，帮助你收集、整理和学习 GitHub 上关于 AI Agent、LLM 等前沿技术的最新文章。

### 核心功能
- 📥 **一键收集**: 自动扫描 GitHub 上最新的 AI Agent 相关文章和讨论
- 🔥 **热度排序**: 根据文章热度、Stars、浏览量自动计算，推荐最有价值的内容
- ❤️ **智能收藏**: 收藏感兴趣的文章，支持本地存储
- 🔍 **强大搜索**: 按关键词、分类快速查找需要的内容
- 📊 **智能分析**: 自动提取和分类不同主题的文章

### 学习相关
- 📚 **适合学生**: 专为计算机大三学生设计的学习工具
- 💡 **精华提炼**: 自动识别和推荐最有教育价值的文章
- 🏷️ **分类管理**: 
  - Agent 框架
  - 大语言模型 (LLM)
  - 提示工程 (Prompt Engineering)
  - 检索增强生成 (RAG)

- 📈 **学习追踪**: 查看你的学习进度和收藏统计

## 📖 使用指南

### 收集文章

1. 点击 **📥 收集最新文章** 按钮
2. 等待收集完成（通常需要 2-5 秒）
3. 文章会按热度自动排序显示

### 热度计算公式

系统自动计算每篇文章的热度分数，综合考虑：

- **新鲜度** (Recency): 发布时间越近，分数越高
- **热度指标** (Stars): GitHub Stars 数量
- **关注度** (Views): 浏览量
- **参与度** (Forks): Fork 数量

```
热度分数 = 新鲜度得分 + Stars对数 × 3 + 浏览量对数 × 2
```

热度等级：
- 🔥 **热门** (分数 > 30): 非常值得深入阅读
- 🌡️ **温暖** (分数 > 15): 很有参考价值
- 📌 **常规** (分数 > 5): 有一定参考价值
- ❄️ **冷门** (分数 ≤ 5): 小众但可能有特殊价值

### 排序方式

点击页面顶部的排序按钮，选择不同的排序方式：

- **🔥 热度**: 根据自动计算的热度分数排序（推荐）
- **📅 最新**: 按发布时间从新到旧排序
- **⭐ Stars**: 按 GitHub Stars 数量排序
- **🎯 参与度**: 按浏览量和参与度排序

### 搜索和筛选

1. **关键词搜索**: 在搜索框输入关键词（如 "LangChain", "AutoGPT"）
2. **分类筛选**: 在下拉菜单选择具体分类
3. **组合使用**: 可以同时使用搜索和筛选获得精准结果

### 收藏管理

- **收藏文章**: 点击任何文章下的 **🤍 收藏** 按钮
- **查看收藏**: 点击页面右上角的 **❤️ 我的收藏** 按钮
- **删除收藏**: 在收藏夹中点击 **❤️** 可删除
- **数据持久化**: 收藏的文章自动保存到本地，不会丢失

## 💾 数据存储

所有数据都存储在你的本地浏览器中：

## 💬 常见问题

### Q: 为什么收集的文章数量有限？
A: 当前版本使用模拟数据。如果想获取更多真实数据，可以集成真实的 GitHub API（需要 GitHub Personal Access Token）。

### Q: 数据会不会丢失？
A: 不会。所有数据保存在本地浏览器的 localStorage 中。但如果清除浏览器缓存会丢失，建议定期导出。

### Q: 可以在多个设备上使用吗？
A: 不行。数据只存储在本地设备上。如果需要跨设备同步，可以导出数据并在其他设备导入。

### Q: 如何更新文章列表？
A: 点击 "收集最新文章" 按钮重新收集。新收集的文章会追加到列表中。
